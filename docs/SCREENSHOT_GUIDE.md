# Adding Screenshots Safely

Screenshots are not included in the initial public portfolio. Before adding any:

1. Use a designated test account and fictitious sample data only.
2. Remove names, phone numbers, emails, addresses, payment information, order references, authentication tokens, and private analytics.
3. Exclude browser address bars if they expose private administrative routes or tokens.
4. Check the image after cropping or blurring; prefer generating a fresh screenshot from test data rather than obscuring private content.
5. Show a small, useful selection: storefront, product detail, cart, inventory overview, and delivery dashboard.
6. Name files descriptively and explain each screenshot without claiming unverified functionality.

Recommended folder: `assets/screenshots/`.

Do not upload the private project repository, `.env` files, database exports, or internal operational documentation.
